Antes de começar
Quem aqui já tem um design system vivo?
E quem tem um arquivo chamado design system?
Não tem resposta errada. A gente já passou pelos dois.
Bloco 01
Design system
no Figma
Antes da ferramenta
Design system é decisão tomada uma vez,
usada mil vezes
Se a decisão não tá escrita em algum lugar, ela vai ser tomada de novo em cada tela. E aí cada tela tem um cinza diferente.
A ordem que funciona pra gente
01
Variáveis primeiro
Cor, espaçamento, raio, tipografia. Nome semântico, não nome de cor.
02
Escala de tipo
Poucos tamanhos, muito uso. Display, corpo, label. Fim.
03
Componentes com props
Variante e estado como propriedade. Nada de sete cópias do botão.
04
Nome que se lê
O naming é a documentação. É por ele que a IA vai entender o sistema depois.
Onde costuma travar
Sistema que ninguém mantém
Componente sem regra de uso
Figma e código contando histórias diferentes
Bloco 02
Design system
no Claude Code
A virada de chave
A IA não precisa de inspiração.
Precisa de contexto.
Enquanto o sistema mora só no Figma, ele é referência. Quando ele vira arquivo — tokens, regras, exemplos — ele vira instrução que roda.
O que a gente entrega pro agente
01
Tokens em CSS
Exportados do Figma, um arquivo só, nome igual ao do design.
02
Guia escrito
Voz, tom, o que nunca fazer. Isso vale mais que a paleta.
03
Componentes reais
Código que já roda. O agente compõe, não recria.
04
Uma skill
O manual da casa: quando usar cada peça e como pedir.
Ao vivo
Vamos rodar
agora
Mesmo pedido, dois contextos: sem o sistema e com o sistema.
Bloco 03
O fluxo
entre os dois
O ciclo
01
Decidir
no Figma
Aqui mora o critério visual e a conversa com o cliente.
02
Exportar
o sistema
Tokens, fontes, guia e componentes numa pasta versionada.
03
Gerar
com a IA
Telas, páginas e variações compostas com as peças que já existem.
04
Devolver
pro sistema
O que provou que funciona vira componente. O resto morre.
O que muda na prática
O ganho não é desenhar mais rápido.
É decidir menos vezes.
Com o sistema no lugar, o tempo vai pra onde importa: entender o problema do cliente e revisar o que a máquina produziu.
